`v8` 模块提供 V8 JavaScript 引擎相关 API，包括垃圾回收控制、堆内存信息查询以及外部内存占用调整等功能。

通过 `require` 获取：

```javascript
const v8 = require("v8");
````

---

### gc

触发 V8 垃圾回收。

该方法会通知 V8 引擎执行低内存处理流程，尝试释放不再使用的内存。

#### 语法

```javascript
v8.gc();
```

#### 参数

无。

#### 返回值

无。

#### 示例

```javascript
const v8 = require("v8");

v8.gc();
```

---

### getHeapSize

获取当前 V8 堆内存统计信息。

#### 语法

```javascript
v8.getHeapSize();
```

#### 参数

无。

#### 返回值

返回一个对象，包含 V8 当前堆内存使用情况。

| 属性                     | 类型    | 说明                              |
|--------------------------|---------|-----------------------------------|
| totalHeapSize            | bigint  | V8 堆总大小（字节）               |
| totalHeapSizeExecutable  | bigint  | 可执行堆空间大小（字节）          |
| totalPhysicalSize        | bigint  | 当前物理内存占用大小（字节）      |
| totalAvailableSize       | bigint  | 可用堆内存大小（字节）            |
| totalGlobalHandlesSize   | bigint  | 全局句柄总大小（字节）            |
| usedGlobalHandlesSize    | bigint  | 已使用全局句柄大小（字节）        |
| usedHeapSize             | bigint  | 已使用堆大小（字节）              |
| heapSizeLimit            | bigint  | 堆内存限制大小（字节）            |
| mallocedMemory           | bigint  | C++ malloc 分配的内存大小（字节） |
| externalMemory           | bigint  | 外部内存大小（字节）              |
| peakMallocedMemory       | bigint  | malloc 分配内存峰值（字节）       |
| numberOfNativeContexts   | bigint  | Native Context 数量               |
| numberOfDetachedContexts | bigint  | 已分离 Context 数量               |
| doesZapGarbage           | boolean | 是否启用垃圾填充保护              |

#### 示例

```javascript
const v8 = require("v8");

const heap = v8.getHeapSize();

console.log(`当前堆使用: ${heap.usedHeapSize} bytes`);
console.log(`堆限制: ${heap.heapSizeLimit} bytes`);
```

### adjustAssociatedMemory

调整 V8 引擎关联的外部内存大小。

当 JavaScript 对象关联了由 C/C++ 管理的外部内存时，可以通过该方法通知 V8 当前外部内存变化，以帮助垃圾回收器进行内存管理。

#### 语法

```javascript
v8.adjustAssociatedMemory(size);
```

#### 参数

| 参数 | 类型   | 必填 | 说明                                     |
|------|--------|------|------------------------------------------|
| size | bigint | 是   | 外部内存变化量（字节），可以为正数或负数 |

#### 返回值

无。

#### 示例

增加外部内存占用：

```javascript
const v8 = require("v8");

v8.adjustAssociatedMemory(1024n);
```

减少外部内存占用：

```javascript
const v8 = require("v8");

v8.adjustAssociatedMemory(-1024n);
```
