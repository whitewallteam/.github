`i18n` 模块提供国际化（Internationalization）相关 API，用于获取和修改当前语言环境中的文本内容。

通过 `require` 获取：

```javascript
const i18n = require("i18n");
````

---

### getString

根据键名获取当前语言对应的文本。

#### 语法

```javascript
i18n.getString(key);
```

#### 参数

| 参数 | 类型   | 必填 | 说明     |
|------|--------|------|----------|
| key  | string | 是   | 文本键名 |

#### 返回值

| 类型   | 说明                 |
|--------|----------------------|
| string | 对应键名的本地化文本 |

#### 示例

```javascript
const i18n = require("i18n");

let text = i18n.getString("menu.start");

console.log(text);
```

---

### setString

设置当前语言环境中的文本内容。

#### 语法

```javascript
i18n.setString(key, value);
```

#### 参数

| 参数  | 类型   | 必填 | 说明             |
|-------|--------|------|------------------|
| key   | string | 是   | 文本键名         |
| value | string | 是   | 要设置的文本内容 |

#### 返回值

无。

#### 示例

```javascript
const i18n = require("i18n");

i18n.setString("menu.start", "开始游戏");
```

#### 注意事项

* `setString` 修改的是当前语言环境中的文本内容。
* 修改后的文本会覆盖原有键对应的翻译内容。
